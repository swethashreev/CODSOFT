# Task 2 - Movie Rating Prediction

## Description
Built a Machine Learning model to predict the rating of a movie
based on features like genre, director, actors, votes and more.

## Dataset
- Movie dataset with features like Genre, Director, 
  Actor, Year, Votes, Duration and Rating

## Tools & Libraries Used
- Python
- Jupyter Notebook / Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Algorithm Used
- Linear Regression
- Random Forest Regressor

## Steps Involved
1. Data Collection
2. Data Preprocessing
3. Handling Missing Values
4. Exploratory Data Analysis (EDA)
5. Feature Engineering
6. Model Training
7. Model Evaluation

## Result
- Predicted movie ratings based on various features
