# Description

Built a Machine Learning model to classify Iris flowers into three species (setosa, versicolor, virginica) based on their sepal and petal measurements.

# Dataset

- IRIS.csv
- Features: sepal_length, sepal_width, petal_length, petal_width, species

# Tools & Libraries Used

- Python
- Google Colab
- Pandas
- Scikit-learn

# Algorithm Used

- Random Forest Classifier

# Steps Involved

1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Encoding
5. Model Training
6. Model Evaluation

# Result

- Classified Iris species with 90% accuracy
- Petal width and petal length identified as the most important features
