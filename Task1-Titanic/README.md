# Task 1 - Titanic Survival Prediction

## Description
Built a Machine Learning model to predict whether a passenger 
on the Titanic survived or not based on features like age, 
gender, ticket class, fare and more.

## Dataset
- Titanic-Dataset-checkpoint.csv
- Features: PassengerId, Survived, Pclass, Name, Sex, Age, 
  SibSp, Parch, Ticket, Fare, Cabin, Embarked

## Tools & Libraries Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Algorithm Used
- Logistic Regression
- Random Forest Classifier

## Steps Involved
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Model Training
6. Model Evaluation

## Result
- Predicted survival of passengers with good accuracy
